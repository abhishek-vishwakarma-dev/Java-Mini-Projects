# Menu-Driven Calculator 🧮

A simple, console-based calculator developed using **Core Java**. It allows users to perform basic arithmetic operations through an interactive menu.

## 🚀 Features

- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division of two numbers.
- Handles division by zero.
- Interactive menu that continues until the user chooses to exit.
- Validates menu choices and displays an error message for invalid options.

## 🛠️ Technologies Used

- Java (JDK 17+)
- Scanner Class
- Switch Statement
- VS Code

## 📚 Java Concepts Practised

- Variables and Data Types
- User Input using `Scanner`
- Infinite `while` Loop
- Conditional Statements (`if-else`)
- `switch` Statement
- Arithmetic Operators
- Type Casting
- `break` and `continue` Statements

## ▶️ How to Run

1. Clone this repository or download the project.
2. Open the `Calculator` folder in VS Code or any Java IDE.
3. Compile the Java file:

   ```bash
   javac Calculator.java
   ```

4. Run the program:

   ```bash
   java Calculator
   ```
